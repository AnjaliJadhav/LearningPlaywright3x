# VS Code Commands — Mac

## General

| Action | Shortcut |
|---|---|
| Command Palette | `Cmd + Shift + P` or `F1` |
| Quick Open (File) | `Cmd + P` |
| Settings | `Cmd + ,` |
| Keyboard Shortcuts | `Cmd + K` `Cmd + S` |
| Extensions | `Cmd + Shift + X` |
| Terminal | `` Ctrl + ` `` |
| Toggle Sidebar | `Cmd + B` |
| Toggle Zen Mode | `Cmd + K` `Z` |
| Close Editor | `Cmd + W` |
| Close Window | `Cmd + Shift + W` |

| Action | Shortcut |
|---|---|

| Move Line Down | `Alt + ↓` |
| Copy Line Up | `Shift + Alt + ↑` |
| Copy Line Down | `Shift + Alt + ↓` |
| Duplicate Selection | `Option + Shift + ↓` |
| Insert Line Below | `Cmd + Enter` |
| Insert Line Above | `Cmd + Shift + Enter` |
| Delete Line | `Cmd + Shift + K` |
| Indent | `Cmd + ]` |
| Outdent | `Cmd + [` |
| Toggle Comment | `Cmd + /` |
| Block Comment | `Shift + Alt + A` |
| Join Lines | `Ctrl + J` |
| Format Document | `Shift + Alt + F` |
| Format Selection | `Cmd + K` `Cmd + F` |
| Go to Line | `Ctrl + G` |
| Go to Bracket | `Cmd + Shift + \` |
| Add Cursor Above | `Cmd + Alt + ↑` |
| Add Cursor Below | `Cmd + Alt + ↓` |
| Multi-select Next | `Cmd + D` |
| Undo Cursor | `Cmd + U` |
| Select All Occurrences | `Cmd + Shift + L` |
| Fold | `Cmd + Alt + [` |
| Unfold | `Cmd + Alt + ]` |
| Fold All | `Cmd + K` `Cmd + 0` |
| Unfold All | `Cmd + K` `Cmd + J` |
