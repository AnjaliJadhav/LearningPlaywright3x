# VS Code Commands — Windows

## General

| Action | Shortcut |
|---|---|
| Command Palette | `Ctrl + Shift + P` or `F1` |
| Quick Open (File) | `Ctrl + P` |
| Settings | `Ctrl + ,` |
| Keyboard Shortcuts | `Ctrl + K` `Ctrl + S` |
| Extensions | `Ctrl + Shift + X` |
| Terminal | `` Ctrl + ` `` |
| Toggle Sidebar | `Ctrl + B` |
| Toggle Zen Mode | `Ctrl + K` `Z` |
| Close Editor | `Ctrl + W` |
| Close Window | `Ctrl + Shift + W` |

## Editing

| Action | Shortcut |
|---|---|
| Cut Line | `Ctrl + X` |
| Copy Line | `Ctrl + C` |
| Move Line Up | `Alt + ↑` |
| Move Line Down | `Alt + ↓` |
| Copy Line Up | `Shift + Alt + ↑` |
| Copy Line Down | `Shift + Alt + ↓` |
| Duplicate Selection | `Ctrl + Shift + ↓` (or `Alt + Shift + ↓`) |
| Insert Line Below | `Ctrl + Enter` |
| Insert Line Above | `Ctrl + Shift + Enter` |
| Delete Line | `Ctrl + Shift + K` |
| Indent | `Tab` or `Ctrl + ]` |
| Outdent | `Shift + Tab` or `Ctrl + [` |
| Toggle Comment | `Ctrl + /` |
| Block Comment | `Shift + Alt + A` |
| Join Lines | `Ctrl + J` |
| Format Document | `Shift + Alt + F` |
| Format Selection | `Ctrl + K` `Ctrl + F` |
| Go to Line | `Ctrl + G` |
| Go to Bracket | `Ctrl + Shift + \` |
| Add Cursor Above | `Ctrl + Alt + ↑` |
| Add Cursor Below | `Ctrl + Alt + ↓` |
| Multi-select Next | `Ctrl + D` |
| Undo Cursor | `Ctrl + U` |
| Select All Occurrences | `Ctrl + Shift + L` |
| Fold | `Ctrl + Shift + [` |
| Unfold | `Ctrl + Shift + ]` |
| Fold All | `Ctrl + K` `Ctrl + 0` |
| Unfold All | `Ctrl + K` `Ctrl + J` |
